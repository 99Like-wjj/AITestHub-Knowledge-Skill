# 代码格式与构建包约束

规范版本：2026-11-14.1。

## FMT01 工具是格式权威

- UTF-8、普通维护文件 LF、两空格缩进；Python 四空格。具体以 .editorconfig 为准。
- TypeScript 和 JavaScript 使用单引号、分号、两空格及末尾逗号，统一由 .prettierrc.json 和现有 Prettier 版本执行。
- 不在同一变更混入无关全库格式化、依赖升级或目录重排。
- Prettier 未覆盖的 Python、PowerShell、SQL 等仍需人工核对风格和语法，不能声称 format:check 覆盖全部语言。

## FMT02 冻结字节例外

.gitattributes、.prettierignore 标明的契约快照、生成规则、Skill 正文及依赖锁等需要保持原字节或由专门流程更新。编辑器自动换行和格式化也可能改 hash，不能因文件看起来“格式不统一”直接重写。

例外是为了保护协议和发行完整性，不是允许将普通新代码放进免检查目录。修改这些内容须说明版本、来源、兼容与摘要变化，生成输出通过其权威构建器更新；不覆盖原冻结归档。

## TYPE01 类型与边界

- 保持现有 strict、noUncheckedIndexedAccess、exactOptionalPropertyTypes 等约束；已开启的 noUnusedLocals、noUnusedParameters 不得关闭以消红。
- 外部输入用 unknown 经 Schema 校验；异常和依赖失败明确处理。any、强制断言、忽略诊断需要局部原因与边界，不能作为普通实现。
- 明确 null、缺失、未知、零和空字符串；ID、修订、序号、Token 与字节数不得任意混用或无损性未知地转 Number。
- 异步调用显式 await 或明确处理；不能吞异常、遗留未处理 Promise，或将未知写结果说成没有发生。
- 接入依赖时检查默认 retry、redirect 和 timeout，不让 SDK 默认策略改变已确认业务语义。

## MOD01 职责与可读性

按领域职责命名、组织文件和接口；控制器、MCP handler、UI 组件不复制领域规则。公共模块只收明确共享能力，不堆成无边界 utils 或万能 service。

拆分应改善职责、依赖和可测性，不能为行数指标制造碎片层。本轮不是强制重排全部既有目录；新代码不得继续扩大已经混杂的职责，相关改动要说明合理边界。

## BUILD01 运行与开发构建

- 当前运行入口和生成输出以实际 tsconfig、package.json、构建脚本为准，不临时使用另一个配置冒充正式构建。
- 运行构建只包含明确应用及运行所需工具。开发、事故诊断、测试和历史脚本放独立入口与忽略目录，不借宽泛 include 混入运行产物。
- 清理输出前验证固定生成根及真实路径；只能清本次负责的生成目录，不删除工作稿、秘密、卷或历史发行物。
- 源码包必须在没有私有测试、证据和开发机绝对路径的情况下构建。不要靠已有 dist 中的残留文件掩盖缺失依赖。
- 使用 packageManager、engines 和锁文件的已定版本；脚本变更不需要假装升级依赖，依赖变更则同步锁文件和许可审查，不追 latest。

## PKG01 源码与分发边界

| 内容                                             | Git 源码             | 分发运行包           |
| ------------------------------------------------ | -------------------- | -------------------- |
| 正式实现、必要构建和运行脚本、可移植配置模板     | 保留                 | 按实际运行需要       |
| 代码引用的 Skill 规则、经验、Schema、许可证      | 保留                 | 保持依赖完整         |
| 生成 bundle、复制契约、integrity、dist           | 按既定忽略与生成策略 | 由明确构建产生并核验 |
| 测试目录、测试专用脚本、私有测试命令和证据       | 仅本地               | 不进入正常产品包     |
| 实例信息、秘密、真实业务资料、设计审核和交接历史 | 不提交               | 不由源码打包夹带     |

源代码能构建、包能解压、完整性通过、宿主安装、自动加载、真实业务及部署分别核对，不互相代替。包 files、复制清单或忽略规则变化后，必须查看实际条目，避免漏运行依赖或夹带本地资料。
