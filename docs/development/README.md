# 当前开发规范

规范版本：2026-11-14.1。

本目录是当前可随源码保留的通用工程约束。根 AGENTS.md 负责让后续 AI 先读这些规则，CONTRIBUTING.md 提供变更入口。规范使用公开的代码结构、参数名称和虚构示例，不记录实例、真实项目或秘密。

## 规则适用关系

- 用户当前指令优先，既有授权在其范围内继续有效。
- 业务范围、权限、状态、删除、停止和重试语义沿已确认需求。本目录不能用“技术规范”另改业务或增加审批。
- 工程组织、配置分类、格式、构建和提交要求以本目录及实际工具配置为准。
- 本地若有 AGENTS.local.md，应读取其中的当前业务和环境边界；它是私有上下文，不提交。带日期的旧快照不能覆盖较新的明确决定。
- 旧 engineering 设计和规范原件保留。其“尚无 package.json”“后续建议脚本”等历史说明，不再作为当前命令清单。

## 开始前读什么

1. [配置与秘密](configuration.md)。
2. [架构与依赖](architecture.md)。
3. [格式与构建包](style-and-packaging.md)。
4. [审查与提交清单](review-checklist.md)。

改动对应规范时同步检查四个仓库的适用内容。共同原则采用同一规范版本，各仓库保留自身入口和命令，不能通过开发机绝对路径或运行时联网下载依赖另一仓库的规则。

## 已接入的检查

| 入口               | 实际检查                                                             | 不能证明                           |
| ------------------ | -------------------------------------------------------------------- | ---------------------------------- |
| pnpm format:check  | package.json 明确列出的源码和配置格式                                | 全语言语义、架构正确性、秘密不泄漏 |
| pnpm format:docs   | 通用 AGENTS、README、贡献/安全/来源说明、当前规范、PR 模板及格式配置 | 私有资料可提交或业务需求已确认     |
| pnpm typecheck     | 当前项目 tsconfig 的严格类型约束                                     | 运行时授权、真实平台或供应商成功   |
| pnpm quality:check | 顺序聚合格式和类型；平台另含独立 client 类型检查                     | 所有审查清单已自动执行             |
| pnpm build         | 本仓库现有构建入口                                                   | 已部署、已安装或业务全量通过       |

ESLint 尚未配置为可执行门禁，不能写“lint 已通过”，也不能调用不存在的 lint 命令。未自动化的语义、架构和隐私检查仍是合入前必查项，不因没有工具而豁免。

检查命令、覆盖路径和工具版本有变化时，同次更新 package.json、锁文件中受影响部分及本目录。不得只改文档，留下不存在或已失效的命令。
