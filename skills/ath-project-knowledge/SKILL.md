# AITestHub 项目知识

由当前AI理解资料、提炼及解释差异；运行工具只处理结构、范围、稳定身份、基准、原提交状态和回执。优先使用宿主已配置的官方AITestHub MCP，按其当前身份操作；不读取Key、Cookie、密码或解析credentialRef。

先确定目标项目/子库与本次资料范围。轻索引用于发现，只有正文明确取回才称已读；不默认整库注入。功能地图说明应用/页面/模块和入口，通用规则保留依据、适用范围、例外及观察/待确认/已确认状态。代码现状不自动成为正确业务规则。

- 整理或按需读取：看[内容与来源](references/content-and-sources.md)。
- 首次双方独立资料、比较或恢复：看[平台工作流](references/platform-workflow.md)。
- 需要持久工作稿、精确原key恢复或集成端口：看[运行工具](references/runtime.md)。

首次两端有独立资料先比较，不按同名/hash认定身份。差异在平台可视化，逐项由人保留本地、平台或合并；未选及缺席保持。普通已明确单项维护不额外增加通用审批。服务端再次验证当前权限与基准，冲突保留双方，恢复生成新修订。

比较会向平台持久化提案，发送前核对接收方、内容和许可；提交授权与内容正确性确认分别判断。所有可视化交互放平台，不生成独立本地HTML或知识服务。平台深链/收据接口未具备时说明具体缺口，继续可独立的整理/发现，不能伪称已同步。

工作稿及真实资料留在库外的显式受限目录。本地授权代码分析只提交经人核对的地图/提炼内容，不上传源码、目录或旧知识v3库；用户选中的旧文字可整理为新提案，不自动升级/覆盖旧库。结构化环境、用途、账号、绑定及连接以平台为权威，知识只说明与引用UUID。

原请求结果未知、宿主退出或平台不可用时，保留原commandId/比较/草稿，先只读查询。404不证明未执行；不自动重发、不换key掩盖未知、不扩大范围。包能加载不代表平台、宿主或真实资料提炼已验收。
