- [ ] 检查 git diff、git diff --cached 和拟提交路径，不使用未经审核的全目录添加。

## 合入前阻断条件

以下情况不能以“先交一版”或“只是私有仓库”为理由放行：

- 实例绑定仍藏在代码里，或模板包含真实值、秘密。
- 检查失败通过关规则、删断言、改历史、改数据或借旧产物绕过。
- 模块依赖、当前权限、不可变快照或副作用一次性边界被破坏。
- 构建或包依赖没有提交的私有文件；分发包夹带测试、真实配置或秘密。
- 只记录“完成”，却没有实际检查结果、未验证范围或必要恢复入口。

## 交付记录

写明规则依据、最终改动、受影响入口、真实命令和结果、迁移或配置影响、未测与剩余风险。只有用户当前任务范围明确授权时才合并、推送或发布，既有授权不反复申请；文档和代码通过不自动恢复暂停的真实模型、系统测试或云端发布。
